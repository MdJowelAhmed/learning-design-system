# 🎨 Enterprise Design System

Welcome to the official component library and documentation hub.

## 🚀 Key Features

- **Monorepo Architecture:** Powered by Turborepo and pnpm workspaces
- **Design Tokens:** Style Dictionary v4 generating DTCG-compliant CSS Variables and TypeScript constants
- **Accessibility:** Full WAI-ARIA compliant keyboard navigation and screen reader support
- **Theme Support:** Native Light/Dark mode with automatic system preference detection
- **Component Standard:** Built with React 19, TypeScript strict mode, CVA, and Tailwind CSS v4

## 📦 Packages

- `@myds/ui` — Core UI components
- `@myds/tokens` — Design token system
- `@myds/theme` — Theme provider & hooks
- `@myds/hooks` — Shared React hooks
- `@myds/utils` — Utilities (cn, a11y helpers)
- `@myds/icons` — Icon system (Lucide React)
